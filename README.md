# Progress

Тестовое задание в OZON. Круговой progress с функцией вращения и сокрытия.

## Сущности

- **script.js** — Entry Point приложения
- **app.js** — скрипт, который собирает все приложение(прогресс компонента + инпуты)
- **components** — компоненты приложения (инпут/свитч/прогресс)
- **controllers** — контролы для управления компонентами(всеми инпутами + прогресс компонент)

## Базовая функциональность

- прокидывание аттрибутов/коллбеков в компоненты
- вращение прогресс компонента
- сокрытие прогресс компонента
- ввод значения прогресс компонента
- адаптивность под ориентацию экрана(portrait/landscape)

## Дефолтные параметры для input

- type | строка | значение по умолчанию: number | тип инпута
- class | строка | значение по умолчанию: input | класс инпута

## Дефолтные параметры для switch-input

- type | строка | значение по умолчанию: checkbox | тип инпута
- class | строка | значение по умолчанию: checkbox | класс инпута

## Дефолтные параметры для progress

- value | число | значение по умолчанию: 0 | текущее значение прогресса (0–100)
- animate | логическое | значение по умолчанию: false | должен ли прогресс компонент вращаться
- hide | логическое | значение по умолчанию: false | скрыт ли прогресс компонент(снимается с анимацией opacity/transform)
- strokeWidth | число | значение по умолчанию: 10 | толщина обводки (линии) круга прогресс компонента, px
- radius | число | значение по умолчанию: 60 | радиус круга прогресс компонента по центральной линии обводки, px
- rotationSpeed | число | значение по умолчанию: 2 | длительность одного полного оборота анимации вращения, секунды
- backgroundColor | строка | значение по умолчанию: '#f7f7f7' | цвет фонового круга (незаполненной части), CSS-цвет
- progressColor | строка | значение по умолчанию: '#0000ff' | цвет заполненной части прогресса (обводки), CSS-цвет

### Также присутствую некоторые константы вне параметров API

- MIN_PROGRESS | число | значение: 0 | минимально допустимое значение прогресс компонента
- MAX_PROGRESS | число | значение: 100 | максимально допустимое значение прогресс компонента (верхняя граница шкалы)
- FULL_CIRCLE | число | значение: 2 * Math.PI | полный угол окружности в радианах — множитель для перевода radius в длину дуги (length = FULL*CIRCLE \* radius)
- STROKE_TRANSITION_DURATION | число | значение: 0.5 | длительность перехода stroke-dashoffset при изменении прогресс компонента, секунды
- STROKE_TRANSITION_TIMING | строка | значение: 'ease' | функция плавности (timing function) для перехода; пустая строка означает отсутствие явной функции — браузер применит ease по умолчанию
- NO_TRANSITION | строка | значение: 'none' | значение transition, отключающее анимацию перехода (когда animate: false)
- STROKE_TRANSITION | строка | значение: 'stroke-dashoffset 0.5s ease' | готовое значение CSS-свойства transition для плавного изменения прогресс компонента

### Помимо вышеперечисленного, в компонентах присутствуют различные методы, которые не используются в текущей реализации, но могут пригодиться при расширении функционала и/или использовании в другом приложении
