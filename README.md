# Progress

Тестовое задание OZON. Круговой прогресс компонент с вращением и скрытием.

## Сущности

- **script.js** — entry point приложения
- **app.js** — скрипт, который собирает всё приложение (компонент прогресса + поля ввода)
- **components** — компоненты приложения (input / switch / progress)
- **controllers** — контроллеры для управления компонентами (всеми полями ввода + компонентом прогресса)

## Базовая функциональность

- передача атрибутов и коллбеков в компоненты
- вращение компонента прогресса
- скрытие компонента прогресса
- ввод значения прогресса
- адаптивная вёрстка под ориентацию экрана (portrait / landscape)

## Дефолтные параметры для input

- type | строка | значение по умолчанию: number | тип поля ввода
- class | строка | значение по умолчанию: input | CSS-класс поля ввода

## Дефолтные параметры для switch-input

- type | строка | значение по умолчанию: checkbox | тип поля ввода
- class | строка | значение по умолчанию: checkbox | CSS-класс поля ввода

## Дефолтные параметры для progress

- value | число | значение по умолчанию: 0 | текущее значение прогресса (0–100)
- animate | логическое | значение по умолчанию: false | должен ли компонент прогресса вращаться
- hide | логическое | значение по умолчанию: false | скрыт ли компонент прогресса (скрывается с анимацией `opacity`/`transform`)
- strokeWidth | число | значение по умолчанию: 10 | толщина обводки (линии) круга компонента прогресса, px
- radius | число | значение по умолчанию: 60 | радиус круга компонента прогресса по центральной линии обводки, px
- rotationSpeed | число | значение по умолчанию: 2 | длительность одного полного оборота анимации вращения, секунды
- backgroundColor | строка | значение по умолчанию: '#f7f7f7' | цвет фонового круга (незаполненной части), CSS-цвет
- progressColor | строка | значение по умолчанию: '#0000ff' | цвет заполненной части прогресса (обводки), CSS-цвет

### Также присутствуют некоторые константы вне параметров API

- MIN_PROGRESS | число | значение: 0 | минимально допустимое значение прогресса
- MAX_PROGRESS | число | значение: 100 | максимально допустимое значение прогресса (верхняя граница шкалы)
- FULL*CIRCLE | число | значение: 2 * Math.PI | полный угол окружности в радианах — множитель для перевода radius в длину дуги (`length = FULL_CIRCLE _ radius`)
- STROKE_TRANSITION_DURATION | число | значение: 0.5 | длительность перехода `stroke-dashoffset` при изменении прогресса, секунды
- STROKE_TRANSITION_TIMING | строка | значение: 'ease' | функция плавности (timing function) для перехода
- NO_TRANSITION | строка | значение: 'none' | значение `transition`, отключающее анимацию перехода (когда `animate: false`)
- STROKE_TRANSITION | строка | значение: 'stroke-dashoffset 0.5s ease' | готовое значение CSS-свойства `transition` для плавного изменения прогресса

### Кроме того, в компонентах есть методы, которые не используются в текущей реализации, но могут пригодиться при расширении функциональности или использовании в другом приложении
